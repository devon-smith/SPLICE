# Reports Provenance

Unless a file says otherwise:

- `*.md` reports in this directory are AI-generated or AI-assisted narrative analysis of run artifacts.
- Numeric claims in those reports should be traced to the referenced scripts, cached scores, JSON files, CSV files, or figures.
- `*.json`, `*.csv`, and figure files are machine-generated outputs from scripts, not AI-generated prose.

Exceptions:

- `project_spec.md` and `related_work.md` are AI-assisted project documents, not run-analysis outputs.
